# Model-book historical replay: 2025-26

All lines and odds below are generated by the model with **no vig**.
No historical sportsbook prices or customer bets were used; this tests
prediction/calibration, not betting ROI, EV or house revenue.

- Game model was trained on 2020-21, 2021-22, 2022-23; 2025-26 is an unseen holdout.
- Games: 1262; home Brier 0.2093, log loss 0.6069, most-likely-side accuracy 67.6%.
- Props: 180,520 graded market quotes and 60,880 void quotes; raw/calibrated OVER Brier 0.2480/0.2451; raw/calibrated log loss 0.6901/0.6832.
- Own-line prop quote: `floor(as-of corrected projection) + 0.5`; OVER/UNDER odds are priced from the predictive distribution and an
earlier-week L10-fitted calibrator. A DNP is void.
- Max game/prop fair-odds overround error: 1.1e-16/2.2e-16.
- Runtime 5.3s; 0 historical odds requests.

Game split:

- Playoffs: 85 games; Brier 0.2195, log loss 0.6297, most-likely-side accuracy 67.1%.
- Regular Season: 1177 games; Brier 0.2085, log loss 0.6052, most-likely-side accuracy 67.6%.
